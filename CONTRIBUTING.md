## 🎫 Ticket Naming Convention

All tasks, issues, and pull requests must follow the standardized format below:

### Format

`[PROJECT_KEY]-[ID]-[SCOPE]: [Short Task Description]`

### Parameters

- **`PROJECT_KEY`**: Always `FLOW`.
- **`ID`**: 3-digit sequential number (e.g., `001`, `002`, `010`).
- **`SCOPE`**: Indicates the area of work:
  - `FE`: Frontend (React, CSS, UI logic)
  - `BE`: Backend (Express, Node.js, Database)
  - `FS`: Full-Stack (Requires both FE and BE changes)

### Examples

- `FLOW-001-FE: Implement Dark / Light Mode Toggle`
- `FLOW-002-FE: Add Real-time Task Search Bar`
- `FLOW-003-FE: Add Task Status Filtering (All / Active / Completed)`
- `FLOW-004-FS: Implement Task Priority Levels (Low / Medium / High)`
